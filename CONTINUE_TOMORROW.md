Open PowerShell and run:


Run:

```powershell
cd "C:\Users\Admin\Desktop\Cайт"
npm.cmd install
npm.cmd run dev
```

## Main Files To Edit

- `src/data/works.js` — portfolio categories and VK video embeds.
- `src/components/Approach.jsx` — section with the creator portrait.
- `public/assets/` — images used by the site.
