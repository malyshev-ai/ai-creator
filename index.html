Предпросмотр Vite-проекта

Это React-проект. Его нужно запускать через Vite.

При открытии исходного index.html через file:// браузер не собирает JSX, React imports, Tailwind и Framer Motion, поэтому приложение не стартует. Используйте npm install и npm run dev для разработки или npm run build и открывайте собранный сайт из dist.
